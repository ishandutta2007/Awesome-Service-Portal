# Awesome-Service-Portal

## Top Service Portal Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Employee Self-Service, IT Help Desk Portals & Digital Workplace Experience*  

**Last updated: October 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Service Portals**. These tools provide a single, intuitive front door for employees and customers to request services, report issues, search knowledge, and track resolution—reducing ticket volume while improving satisfaction and operational efficiency across IT, HR, and facilities.



**Examples** include ServiceNow Service Portal, Freshservice, Jira Service Management, Cherwell Self-Service Portal, BMC Helix Digital Workplace, ManageEngine ServiceDesk Plus, HaloITSM, TOPdesk, SolarWinds Service Desk, and SysAid Portal (the category leaders).



**Open-source emphasis**: This section is expanded with active projects for self-hosted help desk portals, knowledge-integrated ticketing, and employee service hubs—ideal for organizations building sovereign service experience infrastructure without per-agent licensing lock-in.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[ServiceNow Service Portal](https://www.servicenow.com/)**  

  Highly customizable self-service framework built on AngularJS and Bootstrap, featuring a visual Widget Editor for building modular portal components, theme-driven branding, page-based navigation, and deep integration with the Now Platform for catalog items, knowledge articles, and task management; requires admin or `sp_admin` role for configuration .



- **[Freshservice](https://www.freshworks.com/freshservice/)**  

  IT service management portal with a customizable end-user experience, dynamic forms for contextual request intake, service catalog with Shopify-like browsing, conversational bot support, knowledge base integration, employee onboarding module, and built-in CSAT feedback loops for continuous portal improvement .



- **[Jira Service Management](https://www.atlassian.com/software/jira/service-management)**  

  Customer portal with branding controls (name, welcome message, logo, announcements), organized request types, Confluence knowledge base integration for self-service, portal transitions allowing customers to resolve their own requests, optional login-free access, and comment reaction support .



- **[Cherwell Self-Service Portal](https://www.cherwell.com/)**  

  ITSM self-service portal (now part of Ivanti) with codeless configuration, service catalog, knowledge access, and request tracking for enterprise service desks.



- **[BMC Helix Digital Workplace](https://www.bmc.com/it-solutions/bmc-helix-digital-workplace.html)**  

  Self-service application connecting employees to IT and HR on any device; features a configurable end-user console for requests and self-help, an admin console for catalog and feature management, Advanced version adding meeting room reservations and help desk appointments, and Catalog console for service design .



- **[ManageEngine ServiceDesk Plus](https://www.manageengine.com/products/service-desk/)**  

  Service desk with a drag-and-drop portal page editor allowing creation of custom pages from scratch or templates, configurable panels, buttons, widgets (My Summary, Announcements, My Assets), snippets for HTML/Deluge scripts, and mobile apps for on-the-go request submission .



- **[HaloITSM](https://www.haloitsm.com/)**  

  ITSM portal with request types, approval workflows, knowledge base, and multi-department service catalog for managed service providers and internal IT teams.



- **[TOPdesk](https://www.topdesk.com/)**  

  Self-service portal with request submission, knowledge search, and status tracking, designed for IT and facilities service delivery with a user-friendly interface.



- **[SolarWinds Service Desk](https://www.solarwinds.com/service-desk)**  

  Service management portal with employee self-service, service catalog, knowledge base, and incident tracking integrated with SolarWinds monitoring tools.



- **[SysAid Portal](https://www.sysaid.com/)**  

  Self-service portal with AI-powered ticket submission, knowledge base access, and request tracking for mid-market IT service management.



## Open-Source GitHub Projects



- **[Frappe Helpdesk](https://github.com/frappe/helpdesk)**  

  100% open-source ticket management tool with dual portals for agents and customers, customizable SLAs, auto-assignment rules based on priority/issue type/workload, knowledge base with advanced search recommending relevant articles, and saved replies for consistent communication; built on Frappe Framework (Python/Vue) and deployable via Docker or Frappe Cloud .



- **[Znuny](https://github.com/znuny/Znuny)**  

  Open-source ITSM and helpdesk platform (formerly OTRS fork) with a customer self-service portal for viewing previous tickets, checking status, and creating new tickets; includes a centrally managed FAQ/knowledge base integrated into the portal, customer survey module, ticket watch functionality, and ticket splitting/merging; GPL-3.0 licensed and actively maintained .



- **[Zammad](https://github.com/zammad/zammad)**  

  Open-source help desk and customer service platform with a self-service portal where customers can track ticket status, search for solutions, and submit tickets through a user-friendly interface; supports multi-channel intake (email, chat, social, telephony) and knowledge base integration .



- **[FreeITSM](https://github.com/edmozley/freeitsm)**  

  Open-source ITSM tool with a focus on data ownership and simplicity; features multi-tenancy for MSPs, custom asset fields, Active Directory people import, webhooks for Slack/Teams/Discord, service status with historical uptime tracking, and a "Recent" navigation trail that groups records by module for contextual work resumption .



### Additional Strong Open-Source Options



- **osTicket** — Widely used open-source support ticket system with a customer portal for ticket submission and status checking, email piping, and help desk features for smaller teams.

- **Helpy** — Open-source customer support platform with multi-channel ticketing, a knowledge base, and community forums for self-service support.

- **Faveo Helpdesk** — Open-source helpdesk with SLA management, workflow automation, and a self-service portal for multi-channel request handling.

- **OTRS (Community Edition)** — The original open-source ITSM platform from which Znuny was forked; provides a customer portal, ticket management, and workflow automation.



**Frameworks for building custom systems**: Combine **Frappe Helpdesk** for a modern, Docker-deployable portal with knowledge-driven deflection, **Znuny** for ITIL-aligned self-service with FAQ integration, **Zammad** for multi-channel intake with a clean customer portal, and **FreeITSM** for MSP-friendly multi-tenancy in a fully self-hosted service portal stack.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Service portals handling employee and customer data must comply with applicable privacy regulations (GDPR, CCPA, etc.) and organizational security policies.

- Self-hosted open-source solutions require proper security hardening, SSO integration, and knowledge base content curation for effective self-service deflection.

- Verify license terms for commercial use; Frappe Helpdesk is open-source (GPL-3.0), Znuny uses GPL-3.0, Zammad uses AGPL-3.0, and FreeITSM is an independent open-source project.
